Klikk på en illustrasjon for å se detaljer, kopiere SVG-koden eller laste den ned.

<IllustrationLibrary />

## Bruk i kode

```tsx
import { SkjemaMedLupe } from '@digdir/varde/illustrations/uutilsynet/react';

<SkjemaMedLupe aria-hidden />
```

For mørk modus, last også inn stilarket:

```ts
import '@digdir/varde/illustrations/uutilsynet.css';
```
